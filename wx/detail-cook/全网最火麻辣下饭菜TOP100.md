## 一、川渝江湖硬菜（20道）

### 1. 重庆牛油火锅 ★★★★★ 

食材：牛油火锅底料200g、毛肚200g、黄喉150g、鸭肠150g、肥牛卷300g、鸭血200g、虾滑150g、酥肉、各类丸子蔬菜菌菇豆制品
调料：郫县豆瓣50g、干辣椒80g、花椒20g、姜蒜、牛油50g、醪糟30g、冰糖、八角桂皮香叶草果、高汤；蒜泥香油碟（香油+蒜末+盐+香菜）
做法：① 牛油化下豆瓣姜蒜香料小火炒20分钟出红油。② 加底料醪糟冰糖高汤熬30分成红汤锅底。③ 锅底滚开，毛肚鸭肠"七上八下"烫10秒。④ 肥牛卷变色即捞，其他涮菜随烫随吃。
> 📰 公众号标题：《在家煮火锅，七上八下烫毛肚》
博主贴士：毛肚鸭肠"七上八下"烫10秒最脆；蒜泥香油碟解辣护胃。
```
🎤 打油诗：
牛油下锅慢慢化，豆瓣姜蒜香料下。
小火炒二十分红油，底料醪糟冰糖加。
大骨高汤倒进去，熬煮三十分锅底佳。
红汤滚滚开了花，准备涮菜一大家。
毛肚鸭肠七上八下，十秒就捞脆得夸。
肥牛卷烫变色就，酥肉直接吃也巴。
蒜泥香油蘸料调，吃得满头大汗花。
在家煮火锅自在，想吃啥就往锅里抓！
```

### 2. 毛血旺 ★★★★ 

食材：鸭血300g、毛肚150g、黄喉100g、午餐肉150g、鳝鱼片100g、黄豆芽200g、木耳50g
调料：郫县豆瓣40g、干辣椒30g、花椒10g、火锅底料30g、姜蒜、生抽、白糖、高汤、蒜苗
做法：① 鸭血冷水焯2分钟；毛肚黄喉切条、午餐肉切片；豆芽木耳焯水垫底。② 姜蒜豆瓣火锅底料炒红油，加高汤烧开，生抽白糖调味。③ 下鸭血午餐肉鳝鱼煮3分钟，再下黄喉毛肚烫30秒连汤入盆。④ 表面铺椒蒜蒜苗，泼滚油。
> 📰 公众号标题：《老厨子不外传的毛血旺秘诀》
博主贴士：毛肚黄喉最后下，烫老了像嚼橡皮；垫底用黄豆芽才是重庆老传统。
```
🎤 打油诗：

鸭血午餐毛肚片，料酒焯好捞出去。
热油炒香火锅料，豆瓣葱姜爆出红。
添锅高汤煮滚开，下肉煮入味儿浓。
连汤带肉倒碗里，辣椒花椒蒜末撒。
滚油滋啦往上浇，麻辣鲜香就成啦！
```

### 3. 水煮鱼（沸腾鱼） ★★★★★ 

食材：草鱼/黑鱼1条（约2斤）、豆芽300g
调料：郫县豆瓣30g、干辣椒60g、花椒20g、蛋清1个、淀粉20g、姜蒜、料酒、盐、白芝麻、香菜
做法：① 鱼头鱼骨剁块，鱼肉片薄片；鱼片加盐酒蛋清淀粉上浆。② 豆芽焯水垫底。③ 姜蒜豆瓣炒红油，加汤烧开，下鱼骨煮5分钟铺豆芽上；汤微沸下鱼片划散煮1分钟连汤入盆。④ 铺满椒蒜，泼八成热油，撒芝麻香菜。
> 📰 公众号标题：《饭店不会告诉你的水煮鱼秘方》
博主贴士：鱼片切2mm厚，煮到八分熟出锅，余温焖熟。
```
🎤 打油诗：
草鱼杀净片薄片，蛋清淀粉抓上浆。
豆芽焯水铺盆底，鱼骨熬汤奶白香。
豆瓣姜蒜爆红油，汤沸鱼片轻轻放。
一分多钟就关火，嫩得入口直晃荡。

八成热油泼下去，滋啦一声满屋香！
```

### 5. 麻婆豆腐 ★★★★ 

食材：嫩豆腐/石膏豆腐1盒（约400g）、牛肉末100g、青蒜苗
调料：郫县豆瓣30g、永川豆豉10g、汉源花椒粉3g、蒜末、生抽、白糖、水淀粉、高汤、刀口辣椒面
做法：① 豆腐切1.5cm方块，淡盐水焯1分钟捞出保温。② 热油炒散牛肉末至深褐酥香盛出。③ 豆瓣豆豉蒜末刀口辣椒炒红油，加高汤200ml生抽白糖，下豆腐小火烧2分钟。④ 分三次淋水淀粉勾芡，二次芡后下牛肉末蒜苗，三次芡亮油出锅撒花椒粉。
> 📰 公众号标题：《麻婆豆腐八字真言，记住就赢了》
博主贴士：正宗八字诀：麻、辣、烫、香、酥、嫩、鲜、活——牛肉末要酥、豆腐要嫩、三次勾芡保"活"、趁热吃！
```
🎤 打油诗：
嫩豆腐切小方块，淡盐水焯不碎开。
牛肉末炒金黄酥，豆瓣豆豉红油来。
添汤下豆腐咕嘟，小火慢烧味入怀。
水淀粉分三次勾，芡汁裹住豆腐块。
蒜苗切段花椒撒，麻嘴烫舌最痛快。
麻辣烫香酥嫩鲜，趁热扒饭才叫嗨！
```

### 6. 回锅肉 ★★★ 

食材：带皮二刀肉（坐臀肉）/五花肉400g、青蒜苗150g、青椒2个
调料：郫县豆瓣30g（剁碎）、甜面酱15g、太和豆豉5g、白糖、姜片、料酒、花椒
做法：① 二刀肉冷水加姜酒花椒煮至七成熟（筷子扎透无血水），放凉冷藏切2mm薄片。② 蒜苗拍扁切段，青椒切块。③ 少许油下肉片中小火煸至卷曲出油成"灯盏窝"，推锅边。④ 下豆瓣甜面酱豆豉炒红油，合炒加青椒白糖，最后下蒜苗快炒十几秒出锅。
> 📰 公众号标题：《炒出灯盏窝才是正经回锅肉》
博主贴士：正宗用二刀肉（后腿坐臀），肥四瘦六最易出灯盏窝；蒜苗最后下保翠绿清香；豆瓣已咸无需放盐。
```
🎤 打油诗：

放凉切薄二毫米，片儿带皮最是乖。
少许油下肉片煸，炒到卷曲灯盏窝。
豆瓣甜面豆豉爆，红油裹满每片肉。
青椒块下翻炒匀，白糖提味不用多。
蒜苗最后丢进去，十几秒就起锅哟。
一片肉下三碗饭，川菜之魂金不换！
```

### 7. 辣子鸡（歌乐山辣子鸡） ★★★★

做法：① 鸡肉剁1.5cm丁，加盐酒生抽姜片腌20分钟，裹薄淀粉。② 六成热油炸金黄，八成热油复炸30秒至外酥。③ 留底油小火炒香花椒辣椒段至枣红飘香。④ 下鸡丁大火翻炒，生抽白糖调味，撒芝麻葱段出锅。

### 10. 万州烤鱼（麻辣烤鱼） ★★★★ 


食材：草鱼/清江鱼1条（约2.5斤）、土豆条、藕片、豆皮、香芹、洋葱、魔芋

做法：① 鱼从背部劈开不切断，抹盐酒姜腌20分钟，烤箱220度烤20分钟至表皮焦香（或油炸）。② 土豆藕豆皮焯水至八成熟。③ 热油炒香姜蒜豆瓣火锅底料椒椒，加高汤生抽白糖，下配菜煮2分钟。④ 烤好的鱼放铁盘，浇上煮好的配菜汤汁，撒干辣椒花椒孜然泼滚油，撒香菜点酒精灯上桌。

```

```

### 12. 来凤鱼 ★★★★

调料：郫县豆瓣40g、泡椒末30g、泡姜20g、干辣椒、青花椒、姜蒜、料酒、蛋清、红薯淀粉、生抽、白糖、香醋

## 🍳 博主终极贴士（麻辣菜通用法则）

1. 豆瓣酱的正确打开方式：一定要剁碎后小火慢炒出红油，辣椒素和红油才会释放，大火炒糊发苦；陈年郫县豆瓣最佳。
2. 花椒分两种用对场景：青花椒（藤椒/鲜花椒）清香麻，适合凉菜、藤椒鱼、藤椒鸡；红花椒（汉源/茂汶花椒最佳）醇厚麻，适合水煮、毛血旺、火锅；现舂的花椒粉最香，最后撒。
3. 泼油温要够：水煮/毛血旺/辣子鸡最后泼油，油温要到七八成热（冒烟），浇在辣椒花椒蒜末上才能"滋啦"一声激出全部香气；但藤椒油只需六七成防苦。
4. 麻辣味不等于死辣：正宗川味讲究"香辣不燥、麻辣回甜"，白糖是秘密武器——提鲜、中和辣味、让味道更立体，几乎每道麻辣菜都要放一点点糖（吃不出甜味但味道更立体）。
5. 肉类嫩化三件套：蛋清+淀粉+少许食用油封浆，牛肉可加1g小苏打（腌20分钟后冲洗），滑油时油温不要太高，变色即捞；逆纹切是肉嫩的第一前提。
6. 辣椒怎么选：二荆条（香而不辣提红油）、子弹头/小米辣（辣度高）、新一代（颜色红亮）、印度魔鬼椒（变态辣），搭配使用效果最好；做鱼香/泡椒菜必须用泡红辣椒（鱼海椒），不能用豆瓣代替。
7. 火锅底料的隐藏用法：一块火锅底料=麻辣香锅+水煮+干锅+毛血旺+麻辣烫+冒菜底料，家里常备一块能做半本菜谱；加牛奶/醪糟能让汤底更醇厚奶白。
8. 食材新鲜永远是第一位：毛肚黄喉要脆、鱼要现杀、牛蛙要活、鸡要走地鸡，再好的调料也救不了不新鲜的食材；腰骚白筋必须剔净、肥肠面粉+盐+醋搓洗三遍去味。
9. 宫保/鱼香易错点：宫保鸡丁是糊辣荔枝口，干辣椒花椒炝锅+糖醋碗汁，不放豆瓣酱！鱼香肉丝灵魂是泡红辣椒，非豆瓣酱，酸甜小荔枝口。
10. 回锅肉/麻婆豆腐标志：回锅肉首选二刀肉，必须先煮后炒、炒到"灯盏窝"、甜面酱+蒜苗不可少；麻婆豆腐必须牛肉末、三次勾芡、最后撒汉源花椒粉，八字诀"麻辣烫香酥嫩鲜活"。
